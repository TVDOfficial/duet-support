# Duet support website

Public support, privacy and iOS terms pages for Duet. This repository contains the website only.

- Support: https://tvdofficial.github.io/duet-support/
- Privacy: https://tvdofficial.github.io/duet-support/privacy/
- iOS terms: https://tvdofficial.github.io/duet-support/terms/

GitHub Pages publishes the root of the `main` branch. Edit the static HTML and CSS files and push to `main` to update the site.
